# 🖼 Streamlit AI Analizator (Rasmlar)

**PyTorch** va **torchvision** modellari asosida rasmlarni tahlil qiluvchi Streamlit ilovasi. Obyektlarni aniqlaydi va tasniflaydi.

---

## ✨ Imkoniyatlar

- 🔍 **Obyekt aniqlash** (detection model)
- 🏷 **Tasniflash** (classification model)
- 💻 **GPU/CPU** avtomatik tanlash
- 🎨 **Interaktiv interfeys**

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **Streamlit** | Veb-interfeys |
| **PyTorch / torchvision** | Modellar |
| **Pillow** | Rasm bilan ishlash |

## ⚙️ O'rnatish

```bash
git clone https://github.com/dastonbek8747/Streamlit-AI-Analizator-images.git
cd Streamlit-AI-Analizator-images
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

---

## ▶️ Ishga tushirish

```bash
streamlit run main.py
```
